개발 진행 주간 리포트 AI

Jira 이슈 CSV를 넣으면 진척률·지연·막힌 작업·버그는 코드가 집계하고, AI가 주간 리포트를 씁니다. AI가 쓴 숫자와 이슈 번호는 코드가 다시 대조합니다. PM은 검토만 하고 공유합니다.

이슈 CSV코드: 지표 집계AI: 리포트 작성코드: 숫자·이슈 번호 검증PM: 검토 후 공유
시연 데이터는 가상의 "신규 캐릭터 출시" 프로젝트입니다. 시연 CSV 내려받기 · 열: key, summary, type, stage, status, assignee, created, start, due, resolved, points, blocked_by, severity, rework
"시연 데이터로 보기"를 누르면 대시보드와 AI 주간 리포트가 만들어집니다.
숫자는 AI가 만들지 않습니다진척률, 계획 대비 완료율, 연쇄 영향 작업 수, 마일스톤 버퍼는 모두 코드가 계산합니다.
AI 글은 코드가 대조합니다리포트에 나온 이슈 번호와 숫자가 집계에 없으면 경고를 띄웁니다.
PM의 시간은 판단에 씁니다집계와 초안을 자동으로 만들고, PM은 리스크 판단과 결정 요청에 집중합니다.
소스: GitHub · 업로드한 CSV는 저장하지 않습니다.
